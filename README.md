# Grupo Gente Serviços

Site institucional (página única) para uma empresa de terceirização de mão de obra e facilities: limpeza, portaria, segurança patrimonial, jardinagem, apoio administrativo e gestão de facilities.

## Conteúdo

O conteúdo (serviços, textos e dados de contato) é um ponto de partida e deve ser revisado antes de publicar:

- Telefone/WhatsApp, e-mail e endereço em `index.html` estão como placeholders.
- O formulário de contato é apenas uma demonstração (não envia dados) — conecte a um serviço de e-mail ou CRM.
- Os serviços listados podem ser ajustados para refletir a oferta real da empresa.

## Rodar localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Publicar com GitHub Pages

Em Settings → Pages, selecione a branch `main` e a pasta `/ (root)`. O site ficará disponível em `https://<usuario>.github.io/grupo-gente-servicos/`.
